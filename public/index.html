An AI benchmark

Can AI learn how a system works and predict what happens next?

Show an AI a few completed runs of an unfamiliar system. Then give it a new set of events and see if it can predict the outcome before it happens.

01 / Results

How models did

Each model saw the same three practice runs per case and had to work out the hidden rule. This small pilot used four cases with six forecasts each.

Paired checks count how often a model gets both answers right when the same inputs lead to different outcomes under two rules.

These results cover two public test pairs. The reference solver using the examples scored 24/24. The original pilot runs used provider defaults or explicitly disabled extended reasoning.

02 / Example

Two timers. One hidden rule.

Each timer takes two seconds, and starting it again resets the countdown. When one finishes, it either starts the other timer or cancels it. In an earlier run, the model saw the left timer finish and the right timer either start counting down or stay idle.

A forecast from the pilot

The right timer starts at 0 and restarts at 1. What’s happening at 3?

Restarting gives the right timer two more seconds. It finishes at 3 and acts on the left timer, which was idle.

If the rule is “start”Left is counting down.
Right is finished.
If the rule is “cancel”Left stays idle.
Right is finished.

The example uses a clock starting at zero. In the scored pair, these same events occur at times 70, 71, and 73.

03 / Method

How the test works

  1. Observe

    The model sees what happened in three completed runs.

  2. Forecast

    It gets the starting conditions and planned events for a fresh run, then submits its predictions.

  3. Score

    The simulator checks each prediction against the outcome. A separate run supplies the rule to see how well the model applies it.
